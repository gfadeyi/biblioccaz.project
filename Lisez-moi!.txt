3. TRAVAILLER AU QUOTIDIEN (Le workflow Git)
--------------------------------------------
A. Envoyer vos modifs (Depuis votre PC avec Git Bash) :
   1. git add . 
      -> Sens : Prépare tous les fichiers modifiés pour l'envoi.
   2. git commit -m "Explication de la modif" 
      -> Sens : Met une étiquette sur votre travail (ex: "Correction bug").
   3. git push origin main 
      -> Sens : Envoie officiellement votre code sur GitHub.

B. Mettre à jour le VPS (Via MobaXterm) :
   1. cd /var/www/html
   2. sudo git pull origin main 
      -> Sens : Télécharge le code de GitHub sur le serveur pour mettre le site à jour.
